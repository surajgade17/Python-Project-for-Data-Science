# Python Project for Data Science

Final project for the IBM Data Science Professional Certificate — **Python Project for Data Science** course.

## Overview
This project extracts and visualizes historical stock price and quarterly revenue data for **Tesla (TSLA)** and **GameStop (GME)**, then builds interactive dashboards comparing stock performance against revenue over time.

## What's included
- **Question 1–2:** Tesla stock data (via `yfinance`) and Tesla quarterly revenue (via web scraping)
- **Question 3–4:** GameStop stock data (via `yfinance`) and GameStop quarterly revenue (via web scraping)
- **Question 5–6:** Interactive Plotly dashboards for Tesla and GameStop, each showing historical stock price alongside quarterly revenue

## Libraries used
- `yfinance` — historical stock price data
- `requests` + `BeautifulSoup` — web scraping revenue tables
- `pandas` — data cleaning and manipulation
- `plotly` — interactive dashboard visualizations
